# Linux User Management System

A Bash scripting project for Linux administration.

## Features
- Create users
- Delete users
- Create groups
- Add users to groups
- Lock/unlock accounts
- Change passwords
- Show user details

## Technologies Used
- Linux
- Bash Shell
- User Administration Commands

## Commands Used
- useradd
- userdel
- groupadd
- usermod
- passwd
- id
